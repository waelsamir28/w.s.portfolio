# WAEL SAMIR — Graphic Designer & Creative Designer

موقع بورتفوليو احترافي متكامل (Next.js 16 + TypeScript + Tailwind CSS 4 + PostgreSQL + Drizzle ORM) لعرض أعمال التصميم والإعلانات والموشن جرافيك والطباعة، مع لوحة تحكم كاملة لإدارة كل شيء دون لمس الكود.

## التشغيل محليًا

```bash
npm install
npm run dev
```

لإنتاج:

```bash
npm run build
npm run start
```

## أول تشغيل

- عند أول طلب للصفحة الرئيسية تتم تهيئة قاعدة البيانات تلقائيًا (إعدادات، تصنيفات، حساب المدير، ومشاريع **نموذجية** معلَّمة بوضوح بعبارة «نموذج» يمكنك حذفها أو استبدالها بأعمالك الحقيقية).
- بيانات دخول لوحة التحكم: `src/app/admin` (رابط الدخول `/admin/login`)
  - تُقرأ من ملف `.env`:
    - `ADMIN_USERNAME` (الافتراضي: `admin`)
    - `ADMIN_PASSWORD` (الافتراضي: `Wael@2025`)
  - **غيّر كلمة المرور قبل النشر** (عدّل قيمة `ADMIN_PASSWORD` في `.env` ثم امسح جدول admins أو انشر على بيئة جديدة).

> ملاحظة: كلمات المرور مخزنة في قاعدة البيانات مشفرة بتقنية **scrypt + salt** (لا تُخزن كنص صريح)، وجلسات الدخول عبر كوكيز httpOnly مع توكن مخزَّن بشكل hash.

## بنية المشروع

```
src/
├── app/
│   ├── (site)/               # الواجهة العامة (RTL)
│   │   ├── page.tsx          # الرئيسية (أقسام قابلة للترتيب والإخفاء)
│   │   ├── portfolio/        # معرض الأعمال مع فلترة وبحث
│   │   ├── projects/[slug]/  # تفاصيل المشروع (SEO + Lightbox + مشاريع مشابهة)
│   │   ├── services/ about/ contact/ privacy/
│   ├── admin/
│   │   ├── (auth)/login/     # تسجيل الدخول
│   │   └── (panel)/          # لوحة التحكم المحمية
│   │       ├── page.tsx           # نظرة عامة (إحصائيات حقيقية + سجل العمليات)
│   │       ├── projects/          # إدارة المشاريع (إضافة/تعديل/ترتيب/حذف/معاينة)
│   │       ├── categories/        # إدارة التصنيفات (مع نقل المشاريع عند الحذف)
│   │       ├── requests/          # طلبات العملاء + ملاحظات داخلية
│   │       ├── content/           # كل نصوص الموقع وروابط السوشيال
│   │       └── design/            # الألوان/الخطوط/الأقسام + معاينة حية
│   └── api/
│       ├── contact/          # استقبال طلبات العملاء (تحقق + حماية)
│       ├── files/[name]/     # خدمة رفع واسترجاع الصور
│       ├── views/            # عداد زيارات حقيقي
│       └── admin/…           # APIs محمية بجلسة الإدارة
├── components/               # مكونات الواجهة واللوحة
├── lib/                      # auth / settings / seed
├── db/                       # Drizzle schema + client
└── middleware.ts             # حماية /admin
```

- الصور المرفوعة تُحفظ في `data/uploads/` (خارج قاعدة البيانات) وتُخدم عبر `/api/files/…`.
- إعدادات الموقع (محتوى + تصميم) محفوظة في جدول `site_settings` بمستويين: **مسودة** و**منشور** — أي تعديل من اللوحة يُحفظ كمسودة ثم «نشر» يفعّله على الموقع فورًا.

## SEO

- `sitemap.xml` و`robots.txt` مولّدة ديناميكيًا (المشاريع المنشورة فقط).
- لكل مشروع عنوان ووصف وصورة OpenGraph وCanonical URL.
- الصور بتحميل كسول (lazy) وحركة الظهور تحترم `prefers-reduced-motion`.

## النشر (Vercel)

1. ارفع المشروع إلى مستودع Git.
2. في Vercel: أضف متغيرات البيئة `DATABASE_URL` (PostgreSQL متوافق، مثل Neon/Supabase) و`ADMIN_USERNAME` و`ADMIN_PASSWORD` و`NEXT_PUBLIC_APP_URL`.
3. بناء ونشر تلقائي.
4. ملاحظة لرفع الملفات: بيئة Vercel غير دائمة، فالرفع يُخزن محليًا على نظام الملفات — لنشر إنتاجي دائم استبدل مجلد `data/uploads` بخدمة تخزين سحابي (S3/R2) مع الحفاظ على نفس مسار `src/app/api/admin/upload/route.ts`.

## الاختبارات المطلوبة (قائمة تحقق)

- [ ] دخول لوحة التحكم ببيانات `.env` ورفض الوصول بدون جلسة.
- [ ] إنشاء مشروع: رفع غلاف + صور، وصف، تصنيف، وسوم → حفظ كمسودة (لا يظهر) → نشر (يظهر في الرئيسية والمعرض).
- [ ] تمييز مشروع بالنجمة → يظهر في «أعمال مميزة».
- [ ] حذف تصنيف له مشاريع → يطلب اختيار تصنيف بديل.
- [ ] تعديل اللون الأساسي/الخط/الترتيب في «التصميم» → نشر → يتغير الموقع فورًا.
- [ ] إرسال طلب من نموذج التواصل → يظهر في «طلبات العملاء» → تغيير الحالة + ملاحظة داخلية.
- [ ] حذف مشروع → تأكيد → يختفي من الموقع.
